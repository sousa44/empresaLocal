# Empresa Local

Projeto de site institucional desenvolvido com foco em apresentação de serviços empresariais de forma moderna, simples e responsiva.

 **Acesse o projeto online:**
[https://sousa44.github.io/empresaLocal/#](https://sousa44.github.io/empresaLocal/#)

---

##  Sobre o projeto

O **Empresa Local** é um site institucional criado para simular a presença digital de uma empresa que oferece soluções para negócios locais.

O objetivo principal foi praticar e consolidar conhecimentos em desenvolvimento front-end, criando uma interface limpa, organizada e adaptável a diferentes dispositivos.

---

##  Tecnologias utilizadas

* **HTML5** → Estrutura do site
* **CSS3** → Estilização e layout
* **Bootstrap 5** → Responsividade e componentes prontos

---

##  Funcionalidades

* Layout responsivo (desktop, tablet e mobile)
* Menu de navegação fixo
* Seção de apresentação (hero)
* Área "Sobre nós"
* Listagem de serviços
* Botões de ação (call-to-action)

---

##  Aprendizados

Durante o desenvolvimento deste projeto, foram trabalhados:

* Estruturação semântica com HTML
* Organização de layout com CSS
* Uso de classes utilitárias do Bootstrap
* Responsividade 
* Boas práticas de design simples e funcional
